# 決定記録

状態は「確定」「暫定」「未決」で管理する。暫定は利用者の回答や実装検証で見直す。

## 設計変更の書き方

決定が変わったら古い行を消さず、状態と理由を更新する。大きな変更は日付と「何を変えたか・なぜ・影響」をこのファイルに追記する。
