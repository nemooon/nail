## 1. 分類ルールと Workers AI

### 検証方法

1. 本人が実メールから、重要通知5カテゴリ、プロモーション、通常の受信に当たる例を選ぶ。差出人と件名だけで判定しにくい例や、同じ送信元から広告と予約確認が届く例を含める。メール内容をこのリポジトリへ保存しない。
2. 本人の分類を正解として記録し、まず明確なルールだけで判定する。
3. ルールで決まらなかったメールだけ、ヘッダーとテキスト化した本文全体を Workers AI に渡して判定する。添付は渡さない。
4. 「見逃した重要通知」「広告を重要通知と誤判定」「分類不能」「AI の失敗」を別々に集計し、利用者が修正できることを確認する。
5. 入力が長すぎる、HTML からのテキスト抽出に失敗する、モデルが決めた形式を返さない場合は「不明」として受信箱に残す。

### 採用判断

- ルールだけでは見分けにくいメールについて、AI が重要通知の見落としを明らかに減らすか。
- モデル名・分類方式・入力範囲を固定したときの再現性、待ち時間、利用量が日常利用に合うか。
- 分類結果だけを保存し、本文・プロンプト・AI出力の全文を D1 とログに残していないか。

サンプル数が少ない段階では精度の百分率だけで採用を決めない。誤判定したメールを本人が確認し、ルールまたは表示方法で補えるかも判断する。[Workers AI のデータ利用](https://developers.cloudflare.com/workers-ai/platform/data-usage/) / [料金](https://developers.cloudflare.com/workers-ai/platform/pricing/) / [JSON Mode](https://developers.cloudflare.com/workers-ai/features/json-mode/)

## 2. Gmail 初回同期と更新

### 検証方法

- テスト用 Google Cloud プロジェクトで本人のアカウントに接続し、受信箱の件数、最初の一覧が表示されるまでの時間、全件の分類・スタック集計が終わるまでの時間、Gmail API の使用量を測る。
- 途中で画面を閉じる、再開する、Gmail 側で既読・アーカイブする、接続が切れる場合を試す。同期途中の件数は「取り込み中」と示す。
- 初回後は `history.list` の差分同期を試し、履歴切れ時の再同期で重複・欠落が起きないことを確認する。
- 画面表示中の自動更新と手動更新を試し、非表示タブでは定期更新を止める。更新間隔は実際の API 使用量から決める。

受信箱全件の同期が重い場合は、日付でメールを隠さず、新しいメールから表示して残りを段階的に取り込む。試作で遅延と API 使用量を確認してから、ページサイズや同時取得数を決める。[Gmail 同期ガイド](https://developers.google.com/workspace/gmail/api/guides/sync)

## 3. HTML メールの安全な表示

### 表示方針

- MIME から HTML 本文を取り出す。HTML がなければプレーンテキストを表示する。
- 表示前に許可する要素・属性・URL を限定し、スクリプト、イベント属性、フォーム、埋め込みコンテンツ、危険な URL を除去する。
- メール本文のスタイルがアプリ本体へ影響しないよう、隔離した表示領域と CSP を使う。
- 外部画像などの外部リソースは初期状態で読み込まない。明示的な表示操作を設ける場合は、読み込む対象を利用者に示す。
- リンクの遷移先がメール本文によって偽装されないよう、クリック前に実際の行き先を確認できるようにする。

### 検証用メール

予約確認や配送通知など、表・画像・ボタンを含むメールに加え、`script`、`onerror`、`javascript:` URL、CSS の外部読み込み、`iframe`、SVG、壊れた HTML を含むテストメールを用意する。表示時にコードが実行されず、明示操作なしに外部通信が発生しないことをブラウザーで確認する。本文と添付は D1 に保存しない。

## 4. OAuth と権限

既読・アーカイブ・ゴミ箱移動に必要な `gmail.modify` と本人確認用のスコープを、実際に使う API メソッドと照合する。`gmail.modify` には Google 側の仕様として送信能力も含まれるが、このアプリに送信 API は作らない。認可切れからの再接続、本人以外のログイン拒否、更新トークンの失効を検証する。[Gmail スコープ一覧](https://developers.google.com/workspace/gmail/api/auth/scopes)
